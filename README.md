# AIUEO Music Editor

「あいうえおんがく」系の音MADを、**VOCALOID のようなピアノロール UI** で作るためのブラウザ用エディタです。
素材動画から「あ」「い」などの音を切り出してクリップにし、ピアノロールにノートを置いて歌詞を入力すると、
**その歌詞のクリップが、ノートの音程に合わせて映像ごと再生**されます。

## 起動方法

ビルドもインストールも不要です。`index.html` をブラウザ（Chrome / Edge 推奨）で開くだけで動きます。

```sh
# ローカルサーバーで開く場合（任意）
python3 -m http.server 8000
# → http://localhost:8000/
```

## 基本の流れ

1. **素材を開く** で動画（mp4 / webm など）または音声ファイルを読み込む
   （素材がなくても **デモ** ボタンで合成音声の「あいうえお」を試せます）
2. 波形をドラッグして音の範囲を選び、**＋ 選択範囲からクリップ作成**
3. クリップ名を「あ」などにし、**原音の高さ**を確認（作成時に自動推定、**音程推定** ボタンで再推定）
4. ピアノロールに鉛筆ツールでノートを置き、ダブルクリックで歌詞を入力
   （Tab で次のノートへ。**歌詞流し込み** で「あいうえお」とまとめて割り当ても可）
5. Space で再生、**WAV書き出し** / **動画書き出し**（WebM）で完成

## しくみ

| 項目 | 内容 |
| --- | --- |
| 音程変更 | `再生速度 = 2^((ノートの音程 − 原音の高さ) / 12)`。音MAD定番の「速度ごと変える」方式 |
| 映像 | ノートが始まるたびに素材の該当位置へジャンプし、音と同じ速度で再生。次のノートは裏で先読みシーク |
| 和音 | 音声はすべて鳴り、映像は後から始まった（同時なら高い）ノートを表示 |
| 書き出し | WAV は OfflineAudioContext で高速レンダリング、動画はプレビューを MediaRecorder でリアルタイム録画 |
| 保存 | プロジェクトは JSON（素材ファイル本体は含まない）。作業内容はブラウザに自動保存 |

## 操作一覧

| 操作 | 内容 |
| --- | --- |
| Space / Home | 再生・停止 / 先頭へ |
| D / S | 鉛筆 / 選択ツール |
| クリック（空白） | ノート作成（ドラッグで長さ指定） |
| ドラッグ（ノート） | 移動。右端をつかむと長さ変更 |
| ダブルクリック / Enter | 歌詞入力（Tab で次のノート） |
| 右クリック / Delete | 削除 |
| ↑↓（Shift でオクターブ）/ ←→ | 音程変更 / 移動 |
| Ctrl+C / Ctrl+V | コピー / 再生位置へ貼り付け |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直す |
| F | 左右反転（映像） |
| Ctrl+ホイール / Alt+ホイール | 横 / 縦ズーム |
| ルーラーをクリック | 再生位置の移動 |

## ファイル構成

```
index.html        画面レイアウト
style.css         スタイル
src/state.js      プロジェクトデータ・Undo/Redo・自動保存
src/audio.js      音声エンジン（スケジューリング、ピッチ推定、WAV書き出し、デモ合成）
src/preview.js    映像プレビュー（ノートに合わせて素材動画をジャンプ再生）
src/pianoroll.js  ピアノロール
src/sourceview.js 素材波形とクリップ範囲選択
src/main.js       UI の結線
```
